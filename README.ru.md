# STM32F030: часы и бегущая строка

[English](README.md) | Русский

Прошивка для микроконтроллера **STM32F030F4Px** с OLED-дисплеем **SSD1306 128×32**. В обычном режиме часы показывают дату и время RTC, плавно прокручивают строку и мигают разделителями времени. Между обновлениями микроконтроллер переходит в режим пониженного энергопотребления.

[▶ Смотреть видео с текущей версией](https://raw.githubusercontent.com/Lendlav/demo-clock-stm32f0/master/Demo.mp4) · [Исходное видео на YouTube](https://youtu.be/x5GeTt9Zqug)

[![Превью видео Demo](Demo-preview.gif)](https://raw.githubusercontent.com/Lendlav/demo-clock-stm32f0/master/Demo.mp4)

Проект использует CMake, STM32 HAL, CMSIS и FreeRTOS. Логика приложения отделена от кода для микроконтроллера, поэтому форматирование часов не зависит от оборудования и RTOS.

## Возможности

- Читает дату и время из RTC STM32.
- Выводит часы на дисплей SSD1306 128×32 через I²C.
- В режиме часов сдвигает строку на один пиксель каждые 50 мс и мигает разделителями времени каждые 500 мс.
- Анимирует декоративный индикатор батареи в правом верхнем углу; он не измеряет заряд батареи.
- Показывает внутреннюю температуру кристалла STM32 только в виде вертикального значка термометра у правого края; измерение обновляется каждые 5 секунд.
- Измеряет напряжение питания микроконтроллера с помощью VREFINT и показывает его в меню настроек.
- Позволяет менять яркость OLED кнопками. Выбранный уровень не сохраняется и после перезапуска или отключения питания возвращается к значению по умолчанию.
- После пункта меню напряжения питания показывает шагающего персонажа и вращающийся подпрыгивающий каркасный куб.
- После первого кадра передаёт на OLED только те диапазоны страниц, которые изменились.
- Использует tickless idle FreeRTOS и будильник RTC, чтобы между обновлениями переводить STM32 в режим STOP.
- Позволяет устанавливать дату и время RTC тремя кнопками.

> RTC использует внутренний низкочастотный генератор (LSI). Прошивка считывает календарь RTC, но не устанавливает начальные дату и время.

## Структура проекта

| Каталог | Содержимое |
| --- | --- |
| `Domain/` | Типы данных даты и времени, не зависящие от оборудования и RTOS. |
| `Application/` | Форматирование часов, таймер бегущей строки и состояние анимации; код не зависит от оборудования. |
| `Platform/STM32F0/` | Код запуска, настройки HAL, адаптеры RTC и дисплея, задачи FreeRTOS. |
| `Drivers/` | STM32 HAL и поддержка устройств CMSIS. |
| `ThirdParty/FreeRTOS/` | Ядро FreeRTOS и порт для GCC Cortex-M0. |
| `cmake/` | Настройки кросс-компилятора GNU Arm для CMake. |

Задача часов считывает RTC и отправляет кадры через очередь FreeRTOS на один элемент; задача дисплея рисует самый новый кадр. Анимация обновляется 20 раз в секунду. В паузах между кадрами прошивка останавливает SysTick, переводит микроконтроллер в режим STOP с низкопотребляющим регулятором и задаёт будильник RTC на доли секунды, чтобы проснуться перед следующим обновлением. Перед возобновлением FreeRTOS восстанавливается PLL и учитывается время, прошедшее по RTC.

Для измерения температуры и напряжения используется встроенный АЦП STM32F030 и заводская калибровка VREFINT. Термометр показывает температуру кристалла микроконтроллера, а не окружающего воздуха. Отображаемое напряжение — оценка напряжения питания микроконтроллера, а не измерение батареи.

## Энергосбережение

- В режиме часов строка сдвигается на один пиксель за кадр, а разделители времени мигают. Анимированный индикатор батареи декоративный и не показывает напряжение питания.
- Яркость OLED регулируется в 16 шагов; неизменившиеся страницы дисплея повторно не передаются.
- У RTC STM32F030F4/x6 нет таймера пробуждения, поэтому tickless STOP использует сравнение долей секунды будильника A.
- OLED остаётся включённым, чтобы отображать часы или анимацию. Яркость по умолчанию намеренно снижена для уменьшения потребления дисплея.

Прошивка сокращает активность микроконтроллера и снижает яркость OLED, но не измеряет общее потребление платы. На показания тока влияют OLED-модуль, его стабилизатор, индикаторные светодиоды и подключённый ST-Link.

## Оборудование

### OLED-дисплей

| OLED | STM32F030 |
| --- | --- |
| SCL | PA9 / I2C1_SCL |
| SDA | PA10 / I2C1_SDA |
| VCC, GND | Подключите согласно спецификации модуля; используйте логические уровни 3,3 В. |

Прошивка настроена для дисплея SSD1306 128×32. Убедитесь, что подтягивающие резисторы I²C-модуля рассчитаны на 3,3 В.

### ST-Link SWD

| ST-Link | Целевая плата |
| --- | --- |
| SWDIO | SWDIO |
| SWCLK | SWCLK |
| GND | GND |
| VTref / 3.3 V sense | Опорное напряжение 3,3 В целевой платы |

Подайте питание на целевую плату и соедините земли. На многих адаптерах ST-Link контакт VTref является входом опорного напряжения; перед использованием контакта с маркировкой `3.3 V` как выхода питания проверьте документацию адаптера.

### Кнопки настройки часов

Подключите нормально разомкнутые кнопки между указанными GPIO и GND. Прошивка включает внутренние подтягивающие резисторы, поэтому внешние резисторы не нужны.

| Кнопка | STM32F030 |
| --- | --- |
| MODE | PA0 |
| + | PA1 |
| − | PA2 |

Нажимайте MODE, чтобы переключать параметры: часы, минуты, день, месяц, год, яркость, напряжение питания, анимация; затем снова отображается обычный экран. Кнопками + и − изменяется выбранное значение; удержание кнопки повторяет изменение. Изменения RTC записываются сразу. Яркость настраивается в 16 уровнях; напряжение питания и анимация доступны только для просмотра. Шагающий персонаж и вращающийся куб перемещаются по дисплею и заменяют часы, пока пользователь снова не нажмёт MODE.

## Подготовка инструментов для сборки и прошивки

В Debian или Ubuntu установите CMake, GNU Arm Embedded toolchain, Make и утилиты ST-Link. CMake настраивает сборку; в стандартной конфигурации Linux команда `cmake --build` запускает сгенерированные Makefiles.

```sh
sudo apt install \
  cmake build-essential \
  gcc-arm-none-eabi binutils-arm-none-eabi libnewlib-arm-none-eabi \
  stlink-tools
```

Проверьте, что команды доступны:

```sh
cmake --version
arm-none-eabi-gcc --version
arm-none-eabi-objcopy --version
st-flash --version
```

В других дистрибутивах Linux названия пакетов могут отличаться. Установите соответствующие пакеты CMake, GNU Arm Embedded, Make и ST-Link.

## Сборка

Из корневого каталога репозитория настройте и соберите прошивку:

```sh
cmake -S . -B build \
  -DCMAKE_TOOLCHAIN_FILE="$PWD/cmake/arm-none-eabi.cmake" \
  -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

Сгенерированные файлы появятся в `build/`:

| Файл | Назначение |
| --- | --- |
| `demo-clock.elf` | Отладка и информация о символах. |
| `demo-clock.hex` | Образ прошивки в формате Intel HEX. |
| `demo-clock.bin` | Бинарный образ для приведённой ниже команды ST-Link. |
| `demo-clock.map` | Карта памяти и символов компоновщика. |

Конфигурация компоновщика рассчитана на память STM32F030F4: **16 КиБ Flash** и **4 КиБ RAM**.

## Прошивка через ST-Link

1. Подключите ST-Link к SWDIO, SWCLK, GND и контакту опорного напряжения целевой платы. Подайте питание на плату.
2. Убедитесь, что ST-Link обнаруживает программатор и микроконтроллер:

   ```sh
   st-info --probe
   ```

3. Если прошивка ещё не собрана, соберите её, затем запишите бинарный файл и перезапустите микроконтроллер:

   ```sh
   st-flash --reset write build/demo-clock.bin 0x08000000
   ```

`st-flash` записывает бинарный файл в начало внутренней Flash-памяти STM32. Параметр `--reset` перезапускает микроконтроллер после записи, и приложение сразу запускается.

Если программатор не может подключиться при работающем приложении, попробуйте подключение с удержанием микроконтроллера в сбросе:

```sh
st-flash --connect-under-reset --reset write build/demo-clock.bin 0x08000000
```

### Если что-то не работает

- **Программатор или микроконтроллер не найден:** проверьте USB-кабель, питание платы, общий GND, соединения SWDIO/SWCLK и права доступа к ST-Link. Если обычное подключение SWD не работает, попробуйте `--connect-under-reset`.
- **OLED не включается или слишком тусклый:** проверьте питание 3,3 В, землю, SDA на PA10, SCL на PA9 и тип дисплея (SSD1306 128×32 I²C). Выберите настройку яркости кнопкой MODE и увеличьте её кнопкой +.
- **Неверная дата или время:** прошивка не инициализирует календарь RTC при запуске. Установите дату и время кнопками MODE, + и −.
